# Archived source corpus

`harper-valley.highlevel.json` is the original eight-call Harper Valley source slice used during
early product exploration. It remains only as attributed transcript source material; its legacy
expectation fields and historical result files are not part of the current evaluator contract.

The active end-to-end fixture is `prompt-remediation-evaluation-pack.ts` in the API development
module. That fixture uses the production ingestion queue, Success Criteria names, categorical Call
results, and manually requested agent-level Prompt Recommendations.
